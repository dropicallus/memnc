# Skill: repo conventions

Language and provenance rules for every change in this repo.

- English only — no German in source, docs, comments, docstrings, commit messages.
- No date annotations ("verified <date>", "Status: draft") in files. Git history carries provenance; files do not. arXiv IDs and version numbers are fine.
- No personal names or absolute home paths anywhere in content. Use CLI args or env vars for machine-specific values.
- Do not append dated status notes to docs/plan.md or docs/roadmap.md — edit the relevant section in place.
